# 7.7 بيانات الإعداد للفرعين — خطة التعبئة (بلا بيانات مخترعة)

الحالة: **المدقق منفذ، التعبئة تنتظر محتوى المالك — لم تُعبّأ (ما جُرب)**. لا نُدخل بيانات تشغيل مصطنعة في الإنتاج؛ المحتوى يأتي من المالك.

## المدقق (قراءة فقط)
`tests/release-proof/setup_data_checker.sql` — يعمل على أي بيئة بجلسة قراءة:
```
psql "$DATABASE_URL" -f tests/release-proof/setup_data_checker.sql
```
يعرض: عدد الوحدات، وحدات بلا صندوق مفاتيح بالاسم، عدد أسئلة قاعدة المعرفة العامة الفعالة (لكل فرع)، ورابط منصة الحجز لكل فرع، ثم حكمًا واحدًا OK/MISSING.
آخر تشغيل (قاعدة صناعية محلية): MISSING كما هو متوقع. على الإنتاج (قراءة فقط، 24 نوفمبر): 23 وحدة، 0 صناديق مفاتيح، 0 سؤالًا عامًا فعالًا — من سجل المرحلة.

## ما يُملأ ومن أين يأتي
### 1) صناديق مفاتيح للوحدات الـ23 (اليوم: لا صندوق)
- المصدر: المالك يحدد لكل وحدة: موقع الصندوق، الرمز الحالي، تاريخ آخر تغيير.
- الإدخال: من شاشة الوحدة (الرموز) أو دفعة واحدة عبر المالك؛ الرمز الضعيف يُرفض (قاعدة موجودة).
- القبول: المدقق يعرض 23/23 ولا وحدة في قائمة units_without_keybox.

### 2) أهم 20 سؤالًا للنزيل في قاعدة المعرفة (اليوم: فارغة)
- المصدر: المالك/المشرف يكتب السؤال والجواب المعتمدين. الأسئلة العشرون المقترحة كهيكل (ليست محتوى): مواعيد الوصول/المغادرة، الإنترنت، المواقف، الإفطار، العنوان والوصول، هاتف الاستقبال، الحيوانات الأليفة، المصلى، الوصول المبكر، التمديد، فقدان رمز الصندوق، الإلغاء والاسترداد، الفاتورة الضريبية، الأعطال، السرير الإضافي، أنواع الوحدات وأسعارها، حجوزات المنصات الخارجية، الاعتراض على فاتورة، الدفع المتأخر، التدخين.
- الإدخال: is_public=true لكل سؤال يُجاب به النزيل.
- القبول: المدقق ≥ 20 لكل فرع، والمسار الحتمي للمساعد يجيب منها (fn_knowledge_usage_bump يزداد).

### 3) إعدادات الإتاحة عبر المنصات (إن استُعملت)
- قرار 23: الإتاحة العامة للزوار مقفلة؛ المطلوب رابط منصة الحجز لكل فرع تُحوَّل إليه الحجوزات الجديدة.
- المصدر: المالك يحدد رابط المنصة لكل فرع (أو «لا منصات»).
- القبول: المدقق يعرض رابطًا أو قرارًا موثقًا بلا منصات لكل فرع.

## خطوات التنفيذ عند توفر المحتوى
1. استلام محتوى المالك (جدول الوحدات/الرموز + الأسئلة/الأجوبة + روابط المنصات).
2. إدخاله عبر الواجهة أو دالة الإدخال المعتمدة — لا INSERT مباشر.
3. تشغيل المدقق وحفظ مخرجاته OK هنا كدليل إغلاق 7.7.
