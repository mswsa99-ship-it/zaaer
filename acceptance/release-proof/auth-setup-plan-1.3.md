# 1.3 إعداد Supabase (المالك) — خطة التنفيذ والقبول

الحالة: **لم تُنفذ (ما جُرب)** — خطوات لوحة Supabase يملكها المالك وحده؛ لا صلاحية لأي عامل عليها، ولا تغيير حي مسموح به. هذه الخطة جاهزة للتنفيذ بإذن المالك.

## معيار القبول (من الخطة)
1. كلمة «abcdef» يرفضها الخادم نفسه لا الشاشة فقط.
2. رابط التعيين/الاستعادة يعود إلى صفحة التعيين.
3. الرسالة تصل لبريد موظف حقيقي.

## الخطوات (Supabase Dashboard → مشروع الإنتاج)
1. **قاعدة كلمة المرور** — Authentication → Sign In / Providers → Password:
   - Minimum password length: **12**.
   - Required characters: **uppercase + lowercase + digit + symbol** (شغّل كل الخيارات الأربعة).
   - تحقق فوري: من صفحة إنشاء حساب جرّب «abcdef» ثم كلمة من 12 حرفًا بلا رمز — يجب أن يرفض الخادم كلتيهما (رسالة API لا رفض واجهة). الرفض من الخادم هو الدليل، لقطة شاشة لرسالة الخطأ تُحفظ هنا.
2. **عنوان الرجوع** — Authentication → URL Configuration:
   - Site URL: عنوان الموقع الحي.
   - Redirect URLs: أضف مسار صفحة تعيين كلمة المرور (`.../#/set-password` أو مسارها الفعلي في التطبيق). تحقق: رابط الاستعادة في الرسالة يفتح صفحة التعيين لا الصفحة الرئيسية.
3. **بريد الإرسال (SMTP)** — Authentication → SMTP Settings:
   - القرار الحالي: **لا ربط SMTP خارجي (Resend مرفوض من المالك — بانتظار قرار بديل: التسجيل الذاتي للمالك)**. حتى يُبتّ، تبقى الرسائل على بريد Supabase الافتراضي المحدود، والتجربة الحية للبند 1.2/1.4 محجوبة.
4. **القوالب العربية** — Authentication → Email Templates: قوالب Confirm signup وInvite user وMagic Link وRecovery و**OTP** بالعربية، بنصوص التطبيق المعتمدة (نمط: ما حدث، لماذا، الخطوة التالية). قالب OTP يتضمن: الرمز، مدة صلاحيته بالدقائق، تحذير عدم المشاركة، اسم الفندق.
5. **التجربة الحية** (بعد ما سبق): دعوة موظف حقيقي ببريده → تصله الرسالة → الرابط يفتح صفحة التعيين → تعيين كلمة قوية → دخول ناجح. يُحفظ سجل الخطوات ولقطاتها.

## الفجوات المعروفة عند كتابة هذه الخطة
- سجل المرحلة: `password_min_length` ما زال 6 بلا أحرف مطلوبة؛ SMTP غير مضبوط؛ لا تسليم حقيقي مؤكد لرسائل التأكيد/الاستعادة.
- قرار التسجيل الذاتي للمالك (بديل دعوة البريد) معلّق عند المالك/المنسق — يؤثر على الخطوة 3 وعلى 1.2.
